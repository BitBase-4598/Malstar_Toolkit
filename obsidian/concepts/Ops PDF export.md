# Ops PDF export

Download of the current Ops view. The button is labeled Export to PDF and sits in the top bar immediately left of Upload CSV, with the same primary color.

## Definition
The file is built in the browser (`frontend/src/exportOpsPdf.js`). Conclusion text is written first. Images of the overview cards and every performance chart follow. The filename uses the selected dates.
